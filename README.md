# Smart Fridge Assistant

## Overview
Smart Fridge Assistant is a React-based application designed to help you manage your fridge contents efficiently. It allows you to track items and suggest recipes based on available ingredients.

## Features
- Track fridge contents
- Notifications for expiring products
- Recipe suggestions based on available ingredients

## Installation
To get started with the project, clone the repository and install the dependencies:

```bash
git clone https://github.com/yourusername/smart-fridge-assistant.git
cd smart-fridge-assistant
npm install
```

## Scripts
- `npm run dev`: Start the development server
- `npm run build`: Build the project for production


## Usage
1. Start the development server:
    ```bash
    npm run dev
    ```
2. Open your browser and navigate to `http://localhost:5000`.
